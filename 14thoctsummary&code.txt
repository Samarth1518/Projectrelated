# TODAY'S FULL SUMMARY — PDF TO JSON PROJECT

## 1. Project overview

The project is named `PDF_to_JSON`.

The purpose is to read one or more PDFs, extract procedure executions and their STEP details, group executions by their exact procedure names, and generate one combined JSON output.

The project uses:

* Python
* PyMuPDF (`fitz`) to read PDFs
* Regular expressions to parse procedure metadata, STEP IDs, dates, times, and statuses
* `unittest` for automated tests

## 3. Main functionality already implemented

### PDF reading

* `main.py` uses `fitz.open()` to open PDFs.
* It extracts text from each page.
* It counts the number of PDFs read and the total pages read.
* It records diagnostic information and errors.

### Procedure grouping

* Procedure names are used as exact top-level JSON keys.
* Repeated executions with the same exact procedure name are grouped under one `procedures` array.
* Names with different capitalization are treated as different names.
* Executions from multiple PDFs can be grouped together in the same output.

### JSON output

The intended structure is:

## 4. Current `pdf_parser.py` behaviour

The parser contains the following functions:

* `normalize_procedure_name()`
* `normalize_datetime()`
* `split_procedure_blocks()`
* `extract_metadata()`
* `remove_date_time()`
* `is_mode_line()`
* `parse_step_row()`
* `extract_steps()`
* `parse_pdf_text()`
* `validate_execution()`

### Date and time

The parser converts supported date/time values into a normalized format, for example:

`31-Dec-2025 11:44:33:256`

becomes:

`2025-12-31 11:44:33.256`

### Status detection

The parser recognizes:

* `Success`
* `Failure`
* `Suspend`
* `Progress`

These are stored in four arrays under `Status`.

### STEP ID handling

The current regular expression excludes `99.999`:

```python
STEP_ID_RE = re.compile(
    r"^\s*(?!99\.999\b)(\d{2}\.\d{3,4})\b"
)
```

This preserves supported IDs such as `01.001` and `01.002`.

However, the exclusion currently prevents `99.999` from being recognized as a STEP ID. It does not explicitly skip the whole `99.999` row. That could allow its text to be mistakenly attached to the previous STEP. This is a known issue to address.

### Failure reasons

When at least one STEP has a failure status:

* `final_status` is set to `"Failure"`.
* `final_status_reason` becomes a list of dictionaries mapping failed STEP IDs to descriptions.

When there are no failed STEP IDs:

* `final_status` is set to `"Success"`.
* `final_status_reason` is `"None"`.

The desired improvement is to append explanatory text to the short description of a failed STEP without including unrelated content or the next STEP's data.

## 5. Changes made to `parse_step_row()`

## 7. Main issue identified

The current parser needs a more reliable way to distinguish:

* The short STEP description.
* The timestamp and status fields.
* Additional explanatory text belonging to a failed STEP.
* The next STEP's description.
* `MODE` rows, separators, and unrelated table content.

One known issue is that the current `parse_step_row()` logic may discard text after a timestamp on the same line because it slices the line at the timestamp and continues to the next iteration.

Another issue is that `extract_steps()` relies on STEP IDs at the beginning of extracted lines to determine row boundaries. If the PDF's text extraction produces a different layout, the boundary detection may be unreliable.

We need to address both issues without breaking the existing functionality.

## 8. Example of the required failure-reason behaviour

Example source:

```text
01.004     CHECK THIS      12-Dec-2024 11:33:44:456        Failure
-------------------------------------------------------------------------------------------
            WE HAVE CHECKED THIS PROPERLY
-------------------------------------------------------------------------------------------
01.005     CHECK ANOTHER      13-Dec-2024 10:32:14:556        Success
```

Expected failure reason:

```json
[
    {
        "01.004": "CHECK THIS, WE HAVE CHECKED THIS PROPERLY"
    }
]
```

The parser must:

* Include the original failed STEP description.
* Include the explanatory text belonging to that failed STEP.
* Support explanations that span multiple lines.
* Stop before the next STEP ID.
* Exclude the next STEP's description and status.
* Ignore `MODE` rows and separator lines.
* Avoid appending explanatory text to successful steps.
* Preserve the four status arrays and the other execution fields.

This is the target behaviour, not a guarantee that the current parser achieves it.

import re
from datetime import datetime

STATUS_NAMES = ("success", "failure", "suspend", "progress")

MONTHS = {
    "jan": 1, "feb": 2, "mar": 3, "apr": 4,
    "may": 5, "jun": 6, "jul": 7, "aug": 8,
    "sep": 9, "oct": 10, "nov": 11, "dec": 12
}

# Exclude 99.999 while preserving the other supported STEP IDs.
STEP_ID_RE = re.compile(
    r"^\s*(?!99\.999\b)(\d{2}\.\d{3,4})\b"
)

DATE_TIME_RE = re.compile(
    r"(?<!\d)(\d{1,2})[-/]([A-Za-z]{3}|\d{1,2})[-/](\d{4})"
    r"\s+(\d{1,2}):(\d{2}):(\d{2})[:.](\d{1,3})(?!\d)",
    re.IGNORECASE
)

DATE_RE = re.compile(
    r"(?<!\d)\d{1,2}[-/](?:[A-Za-z]{3}|\d{1,2})[-/]\d{4}(?!\d)",
    re.IGNORECASE
)

TIME_RE = re.compile(
    r"(?<!\d)\d{1,2}:\d{2}:\d{2}[:.]\d{1,3}(?!\d)"
)

DURATION_RE = re.compile(
    r"\bDur\s*:\s*(\d+(?:\.\d+)?)\s*\(s\)",
    re.IGNORECASE
)

STATUS_RE = re.compile(
    r"^(Success|Failure|Suspend|Progress)$",
    re.IGNORECASE
)


def normalize_procedure_name(name):
    # Retained for compatibility with existing code and tests.
    # main.py uses the exact extracted procedure name as its key.
    return re.sub(r"\s+", " ", (name or "").strip()).lower()


def normalize_datetime(value):
    match = DATE_TIME_RE.search(value or "")

    if not match:
        return None

    day, month_text, year, hour, minute, second, millis = (
        match.groups()
    )

    if month_text.isdigit():
        month = int(month_text)
    else:
        month = MONTHS.get(month_text.lower()[:3])

    if not month or not 1 <= month <= 12:
        return None

    try:
        parsed = datetime(
            int(year),
            month,
            int(day),
            int(hour),
            int(minute),
            int(second)
        )
    except ValueError:
        return None

    millis = millis[:3].ljust(3, "0")

    return (
        parsed.strftime("%Y-%m-%d %H:%M:%S")
        + "."
        + millis
    )


def split_procedure_blocks(text):
    matches = list(
        re.finditer(r"\bProcedure\s*:", text, re.IGNORECASE)
    )

    blocks = []

    for index, match in enumerate(matches):
        start = match.start()

        end = (
            matches[index + 1].start()
            if index + 1 < len(matches)
            else len(text)
        )

        blocks.append(text[start:end])

    return blocks


def extract_metadata(block):
    name_match = re.search(
        r"\bProcedure\s*:\s*(.*?)\s+\bTime\s*:",
        block,
        re.IGNORECASE | re.DOTALL
    )

    name = ""

    if name_match:
        name = re.sub(
            r"\s+", " ", name_match.group(1)
        ).strip()

    # Procedure metadata is extracted only from the header,
    # before the STEP table.
    table_match = re.search(
        r"\bSTEP\s+ID\b", block, re.IGNORECASE
    )

    header = (
        block[:table_match.start()]
        if table_match
        else block
    )

    time_match = DATE_TIME_RE.search(header)

    date_time = (
        normalize_datetime(time_match.group(0))
        if time_match
        else None
    )

    duration_match = DURATION_RE.search(header)

    duration = (
        int(float(duration_match.group(1)))
        if duration_match
        else None
    )

    return name, date_time, duration


def remove_date_time(value):
    value = DATE_TIME_RE.sub(" ", value)
    value = DATE_RE.sub(" ", value)
    value = TIME_RE.sub(" ", value)

    return re.sub(r"\s+", " ", value).strip()


def is_mode_line(line):
    return bool(
        re.match(r"^\s*MODE\b", line, re.IGNORECASE)
    )


def parse_step_row(step_id, row_lines, warnings):
    description_parts = []
    additional_failure_parts = []

    found_status = None
    description_finished = False

    for raw_line in row_lines:
        line = raw_line.strip()

        if not line:
            continue

        # MODE rows and separator lines are not descriptions.
        if is_mode_line(line):
            continue

        if re.match(r"^[\s\-_=*|]+$", line):
            continue

        # Detect a status appearing on its own line.
        status_match = STATUS_RE.match(line)

        if status_match:
            found_status = status_match.group(1).lower()
            continue

        # Detect a status at the end of a line.
        # Only treat it as the table status when the line
        # also contains a date or time.
        suffix_match = re.search(
            r"\b(Success|Failure|Suspend|Progress)\s*$",
            line,
            re.IGNORECASE
        )

        has_date_or_time = bool(
            DATE_RE.search(line) or TIME_RE.search(line)
        )

        if suffix_match and has_date_or_time:
            found_status = suffix_match.group(1).lower()

            line = line[:suffix_match.start()].strip()

        date_match = DATE_RE.search(line)
        time_match = TIME_RE.search(line)

        positions = []

        if date_match:
            positions.append(date_match.start())

        if time_match:
            positions.append(time_match.start())

        if positions:
            # The first date/time marks the boundary between
            # the short STEP description and any extra details.
            boundary = min(positions)

            description_text = line[:boundary].strip()

            if description_text:
                if not description_finished:
                    cleaned = STEP_ID_RE.sub(
                        "", description_text
                    ).strip()

                    if cleaned:
                        description_parts.append(cleaned)

            description_finished = True
            continue

        # Before the timestamp, collect the short description.
        if not description_finished:
            cleaned = remove_date_time(line)
            cleaned = STEP_ID_RE.sub("", cleaned).strip()

            if cleaned:
                description_parts.append(cleaned)

        else:
            # After the timestamp, retain possible explanatory
            # text separately. Include it only if the final
            # detected status for this STEP is Failure.
            cleaned = remove_date_time(line)
            cleaned = STEP_ID_RE.sub("", cleaned).strip()

            if cleaned:
                additional_failure_parts.append(cleaned)

    description = re.sub(
        r"\s+", " ", " ".join(description_parts)
    ).strip()

    additional_failure_text = re.sub(
        r"\s+",
        " ",
        " ".join(additional_failure_parts)
    ).strip()

    # Additional explanatory text belongs only to failed STEP IDs.
    if found_status == "failure" and additional_failure_text:
        if description:
            description += ", " + additional_failure_text
        else:
            description = additional_failure_text

    if found_status is None:
        warnings.append(
            "STEP " + step_id +
            " has no confidently detected status; "
            "it was not added to a status list."
        )

    return found_status, description


def extract_steps(block):
    status = dict(
        (name, []) for name in STATUS_NAMES
    )

    descriptions = {}
    warnings = []

    lines = block.splitlines()

    table_started = False
    rows = []
    current_id = None
    current_lines = []

    for raw_line in lines:
        line = raw_line.strip()

        if not line:
            continue

        # The table header can occupy one line or several lines.
        if (
            not table_started
            and re.search(r"\bSTEP\s+ID\b", line, re.IGNORECASE)
        ):
            table_started = True
            continue

        if not table_started:
            continue

        # MODE rows terminate the current STEP.
        if is_mode_line(line):
            if current_id is not None:
                rows.append((current_id, current_lines))
                current_id = None
                current_lines = []

            continue

        step_match = STEP_ID_RE.match(line)

        if step_match:
            if current_id is not None:
                rows.append((current_id, current_lines))

            current_id = step_match.group(1)
            remainder = line[step_match.end():].strip()

            current_lines = (
                [remainder] if remainder else []
            )

        elif current_id is not None:
            # Continuation text stays with the current STEP
            # until another recognized STEP ID or MODE row.
            current_lines.append(line)

    if current_id is not None:
        rows.append((current_id, current_lines))

    seen_ids = set()

    for step_id, row_lines in rows:
        if step_id in seen_ids:
            warnings.append(
                "Duplicate STEP ID " + step_id +
                " found within one procedure execution."
            )

        seen_ids.add(step_id)

        step_status, description = parse_step_row(
            step_id, row_lines, warnings
        )

        descriptions[step_id] = description

        if step_status in STATUS_NAMES:
            status[step_status].append(step_id)

    return status, descriptions, warnings


def parse_pdf_text(text, source_name="unknown PDF"):
    executions = []
    warnings = []

    blocks = split_procedure_blocks(text)

    if not blocks:
        warnings.append(
            source_name +
            ": no Procedure: headers were detected."
        )

    for index, block in enumerate(blocks, 1):
        name, date_time, duration = extract_metadata(block)

        if not name:
            warnings.append(
                source_name + ": execution " + str(index) +
                " has no procedure name."
            )

        if date_time is None:
            warnings.append(
                source_name + ": execution " + str(index) +
                " has an unrecognized header timestamp."
            )

        if duration is None:
            warnings.append(
                source_name + ": execution " + str(index) +
                " has an unrecognized duration."
            )

        status, descriptions, row_warnings = extract_steps(block)

        for warning in row_warnings:
            warnings.append(
                source_name + " / execution " +
                str(index) + ": " + warning
            )

        if status["failure"]:
            final_status = "Failure"
            final_reason = []

            for step_id in status["failure"]:
                reason = descriptions.get(step_id, "")

                final_reason.append({
                    step_id: reason
                })

                if not reason:
                    warnings.append(
                        source_name + ": failed STEP " +
                        step_id +
                        " has no extracted description."
                    )

        else:
            final_status = "Success"
            final_reason = "None"

        executions.append({
            "Procedure Name": name,
            "date_time": date_time if date_time else "",
            "Dur": duration if duration is not None else 0,
            "Status": status,
            "final_status": final_status,
            "final_status_reason": final_reason
        })

    return executions, warnings


def validate_execution(execution):
    issues = []
    status = execution.get("Status", {})

    for name in STATUS_NAMES:
        if (
            name not in status
            or not isinstance(status[name], list)
        ):
            issues.append(
                "Status key '" + name +
                "' is missing or invalid."
            )

    all_ids = []

    for name in STATUS_NAMES:
        all_ids.extend(status.get(name, []))

    if len(all_ids) != len(set(all_ids)):
        issues.append(
            "A STEP ID appears more than once "
            "across status categories."
        )

    if execution.get("final_status") not in (
        "Failure", "Success"
    ):
        issues.append(
            "final_status must be Failure or Success."
        )

    if (
        status.get("failure")
        and execution.get("final_status") != "Failure"
    ):
        issues.append(
            "A failed STEP exists but final_status "
            "is not Failure."
        )

    if (
        not status.get("failure")
        and execution.get("final_status") != "Success"
    ):
        issues.append(
            "No failed STEP exists but final_status "
            "is not Success."
        )

    return issues
